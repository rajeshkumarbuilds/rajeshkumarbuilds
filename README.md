## Projects I've Built

### 01. FormFlow — Multi-Step Application Form

A multi-page form application designed to collect personal information, educational details, addresses, and supporting documents.

- Multi-step form navigation.
- Form data persistence using LocalStorage.
- Document storage using IndexedDB.
- Preview and edit application details.
- Client-side validation and responsive layouts.

**Technologies:** HTML, CSS, JavaScript, LocalStorage, IndexedDB.

### 02. PDF Merger

A web application that allows users to upload PDF files and merge them into a single document.

- PDF uploads using Multer.
- Backend processing with Express.js.
- Merging PDFs with a Node.js library.
- Static file serving and generated document handling.

**Technologies:** Node.js, Express.js, JavaScript, Multer.

### 03. Food-Delivery-Web

A food-web interface built to practice component-based development, API integration, and state management.

- Fetching products from external APIs.
- food listing and rendering.
- food cart state management.
- Quantity updates and price calculations.

**Technologies:** React, Redux Toolkit, JavaScript, Tailwind CSS.
